# Food-menu
Restaurant menu with four categories, grid layout, and nature colors.منوی رستوران با چهار دسته، گرید و رنگ‌های طبیعت.



## 📖 درباره‌ی پروژه

این پروژه یک صفحه‌ی منوی دیجیتال برای رستوران‌ها و کافی‌شاپ‌ها است که با استفاده از **HTML** و **CSS** خالص طراحی شده است. این صفحه شامل ۴ دسته‌بندی اصلی غذایی است و با چیدمان گریدی (Grid) و فلکس‌باکس (Flexbox) پیاده‌سازی شده است تا تجربه‌ی کاربری زیبا و منظمی را ارائه دهد.

### ✨ ویژگی‌های اصلی

- **۴ دسته‌بندی غذایی**: پیش‌غذا، غذای اصلی، نوشیدنی، دسر
- **چیدمان گریدی (Grid)**: نمایش منظم و زیبای آیتم‌ها
- **پالت رنگی طبیعت**: ترکیب رنگ‌های کرم، سبز روشن، سبز متوسط و سبز تیره
- **طراحی واکنش‌گرا (Responsive)**: سازگار با نمایشگرهای مختلف
- **نمایش قیمت و توضیحات**: هر آیتم دارای قیمت و توضیحات مختصر است
- **کد تمیز و خواناترین**: استفاده از متغیرهای CSS (Custom Properties) برای مدیریت آسان رنگ‌ها
